# Stage A additions: diagnostic and sensitivity decisions

The RF baseline and all its predictions are frozen. These additions do not tune a model on the tutorial reference.

- Use the existing 2,000-replicate paired spatial-block bootstrap; report 95% percentile intervals per class and macro. Report the unweighted share of blocks with positive S2-like-minus-EnMAP MAE both for all blocks with reference pixels and the >=20-pixel reporting subset. Contexts include dominant-reference class, impervious gradient, and vegetation-fraction bins. The unit of resampling is a block, not a pixel; adjacent blocks are not guaranteed independent.
- Water diagnosis uses the mean retained VNIR channels (<1000 nm) and SWIR channels (>1500 nm), displayed as input values divided by 10,000. A shadow-like proxy requires **both** means below their 20th percentile over all finite image pixels; it is not a verified shadow label. False-water examples require reference water <=0.01 and RF predicted water >=0.25. Examples are selected deterministically: median-brightness pure reference water; largest false water prediction among dark nonwater; largest among above-median-brightness nonwater. They are diagnostic examples, not an unbiased accuracy sample. No normalization or water correction is fitted or tested.
- SVR uses StandardScaler fitted on synthetic training mixtures only, followed by RBF SVR. A **single common C/epsilon pair** is selected from C={1,10,100}, epsilon={0.01,0.05}, gamma='scale', minimizing mean absolute error pooled over the four target classes and both sensors on **400 independent synthetic mixtures/class**. Original endmembers enter training but not the validation pool. The validation mixtures use separate fixed seeds, and share the same source library; this tests mixture interpolation, not new-material generalization.
- The common selected pair is frozen before evaluating any SVR reference error, then used for three paired synthetic-training seeds, matching RF baseline seeds. All SVR fraction predictions are clipped to [0,1] under this predeclared rule; no sum-to-one constraint is applied. Raw out-of-range frequency is saved. Bounds are part of this labelled sensitivity variant, never a replacement RF baseline.
- Both sensors use exactly the same mixture weights, targets, validation mixtures and parameter-selection objective. Reference polygons are not passed to the SVR parameter-selection function.
